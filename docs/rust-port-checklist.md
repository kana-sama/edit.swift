# Чеклист переноса Edit из Rust в Swift

Срез на 21 ноября 2026 года. Сверены 10 фич из спецификаций Rust Edit (`4519cb698b95`) с реализацией и проверками Swift Edit (`515389e38deb`). Вложенные пункты отмечают отдельные сценарии, которые уже работают или ещё отсутствуют.

Swift Edit использует одно окно на документ. Переход между файлами рассчитан на Control по недавним файлам и автосохранение текущего документа.

## Ход переноса

- **В работе:** итоговая проверка сборки, интерфейса и составного ввода с мультикурсором.
- **Дальше:** сверить итоговые сборки Debug и Release и обновить статус проверки.
- **Проверка:** после каждой фичи сверить её сценарии в Swift, прогнать сборку и зафиксировать результат в этом файле.

## Перенесено

- [x] **Базовый редактор.** Нативное окно macOS, фокус на пустом буфере, Unicode и системные методы ввода, курсор и выделение, навигация, буфер обмена, Undo и Redo. Перенесены команды для строк, включая копирование и вырезание текущей строки без выделения, вставку целой строки, отступы, перемещение строк и вставку выше или ниже. Есть подсветка текущей строки, масштаб текста, горизонтальная прокрутка без переноса строк, вертикальная прокрутка, меню и полноэкранный режим. Swift использует оформление и поведение контролов AppKit. [Rust](../../edit/docs/features/editor/spec.md) · [Swift](features/editor/spec.md)

- [x] **Недавние файлы.** File → Open Recent показывает последние десять файлов. История из 500 записей переживает перезапуск, объединяет ссылки на один файл и чистит подтверждённые удаления. Проверены сохранение истории и пункты меню. [Rust](../../edit/docs/features/recent-files/spec.md) · [Swift](features/recent-files/spec.md)

- [x] **Control · Go to File.** Палитра `⌘P` ищет по недавним файлам. Поддержаны поиск по имени и пути, ранжирование, навигация, открытие или фокусировка окна и удаление записи из истории. Проверены поиск, отрисовка списка и пустое состояние. [Rust](../../edit/docs/features/control/spec.md) · [Swift](features/control/spec.md)

- [x] **Control · Command Mode.** `⇧⌘P`, поиск и запуск команд нативного меню, подсказки клавиш, переход по `>` и история команд. Каталог подхватывает команды новых фич по мере подключения меню. [Rust](../../edit/docs/features/control-commands/spec.md) · [Swift](features/control-commands/spec.md)

- [x] **Файлы и сессия.** [Rust](../../edit/docs/features/files/spec.md) · [Swift](features/files/spec.md)
  - [x] Открытие файла системным диалогом и по аргументу запуска. Swift также принимает файлы из Finder. Относительные пути работают от каталога, из которого вызвана команда. Первый файл может занять пустое окно.
  - [x] Save и Save As, сохранение UTF‑8 BOM и существующих переводов строк, защита от перезаписи внешних изменений, возможность сохранить файл по пока не существующему пути через запуск исполняемого файла. В Swift дополнительно доступен выбор кодировки при сохранении.
  - [x] Защита несохранённых правок при закрытии, восстановление открытых документов и их черновиков, активного окна, размеров, положения и полноэкранного состояния. При отсутствии прежнего дисплея окно возвращается на доступный экран.
  - [x] `⌘N` заменяет буфер в текущем окне после сохранения или подтверждения, `⇧⌘N` открывает новое окно, `⌘W` закрывает текущее окно.
  - [x] Совпадающие пути, симлинки и жёсткие ссылки активируют уже открытое окно.
  - [x] Установленная команда `edit [file ...]` и `./script/run [file ...]` принимают относительные пути и ещё не существующие файлы.

- [x] **Мультикурсор.** Добавление курсоров, выделение совпадений, история выделений, правки и команды строк с единым Undo. Ввод через составной IME идёт через основной курсор. Проверены комбинации клавиш, Unicode, отрисовка выделений и операции с буфером обмена. [Rust](../../edit/docs/features/multicursor/spec.md) · [Swift](features/multicursor/spec.md)

- [x] **Подсветка синтаксиса и языковые режимы.** Фоновый Tree-sitter для 23 языковых режимов, автоопределение, ручной выбор, Plain Text и восстановление назначенного режима. Палитра языков открывается через **Change Language Mode…**. Прогнаны реальные грамматики и изолированная отрисовка в TextKit. [Rust](../../edit/docs/features/syntax-highlighting/spec.md) · [Swift](features/syntax-highlighting/spec.md)

- [x] **Иконки файлов.** Seti в Open Recent, Go to File и Search, с вариантами для светлой и тёмной темы и учётом ручного языкового режима. [Rust](../../edit/docs/features/file-icons/spec.md) · [Swift](features/file-icons/spec.md)
- [x] **Find and Replace.** Нативная боковая панель, поиск по черновику, Unicode, регулярные выражения, исключение отдельных совпадений, предпросмотр и замена с Undo. Проверены переходы через Control и автосохранение после замены. [Rust](../../edit/docs/features/find-replace/spec.md) · [Swift](features/find-replace/spec.md)

- [x] **Автосохранение.** [Rust](../../edit/docs/features/autosave/spec.md) · [Swift](features/autosave/spec.md)
  - [x] Фоновая запись файла с путём при потере фокуса редактором, переключении приложения или окна, сворачивании, открытии меню или файловой панели. В Swift также есть таймер в одну секунду после последней правки.
  - [x] Автосохранение перед закрытием, заменой буфера и выходом. Записи согласованы с ручным сохранением, конфликт не затирает внешний файл, а несохранённый текст остаётся доступен в редакторе или восстанавливается из сессии.
  - [x] Открытие Control и выбор файла в палитре запускают автосохранение текущего документа.
  - [x] Переход в Search и правки через Find and Replace запускают автосохранение.
  - [x] Снимок создаётся в момент запроса. Следующие правки сохраняют отметку несохранённого текста. Проверено автосохранение результата Undo.
  - [x] При неудачной записи Swift сохраняет черновик в сессии и сообщает об ошибке перед выходом из активного окна.
