# Smart Typing

- Typing an opening bracket, quote, or backtick wraps a selection and keeps the contents selected. Closing brackets replace the selection. An opening delimiter also replaces the selection if any selection consists only of whitespace or any caret is empty. Multiline wrapping preserves the selected text and line endings.
- At the end of a line or before whitespace or `)]},;:.`, typing an opener inserts the pair and places the caret between its characters. Swift, JavaScript, JSX, TypeScript, and TSX also pair backticks. In other positions, insert the typed character. With current bracket information, reuse a matching unmatched closer later in the same editing scope. A quote following an odd number of backslashes is literal. An opening quote immediately after a word character inserts just the typed quote. Paste and input-method composition retain their literal text.
- Typing an auto-inserted closer at its position moves the caret past it. Backspace between the two adjacent characters of an auto-inserted pair removes both. With multiple carets, pair deletion applies when all of them are inside adjacent auto-inserted pairs. Undo restores the pair and its tracking. Backspace inside leading indentation removes text to the previous tab stop.
- Return copies the current line's indentation before the caret. After an opening `(`, `[`, or `{` or a Python block header ending in a colon, Return indents to the next stop. Allow spaces and tabs between the opener and caret. If a matching closer follows an empty caret on that line, possibly with intervening spaces or tabs, put the closer on its own line and place the caret on the indented line between them. Preserve the existing whitespace before the closer and use the document's line ending for each inserted break.
- With an empty caret, Tab inserts a tab or enough spaces to reach the next stop. On a whitespace-only line, bring the indentation up to the surrounding code's level first. With a selection, Tab indents affected lines by one level. An existing tab advances to the next tab stop in the editor.
- Apply editing commands within editable ranges, including in Focus. A single keystroke edits the buffer as one Undo step. Undo and Redo restore the text and caret locations for wrapping, deleting and splitting pairs.

## File indentation

Click the filename in the [document header](../document-header/spec.md) to open the native popover with **Indent using** and **Tab width**. Choose Automatic, Spaces, or Tabs and a width from one to eight columns. Automatic samples the opened file for tabs and common space indentation widths, with four spaces as the fallback. Choose Automatic again to resample the current contents. Changing the controls applies to the editor immediately and preserves the buffer and selection. Save overrides per file, share them across windows showing the same file, and move them when relocating files through Edit. Untitled overrides apply to their current buffer and carry over on the first save.

## Acceptance

- In `fn () `, type `{` then Return. Check that the caret sits on a blank line four spaces in and that `}` sits on the following line. Undo and redo both steps, then type past the generated closer.
- Wrap multiline Unicode with a quote and undo the wrap. Check closing brackets, whitespace-only selections, mixed selections and carets, and JavaScript backtick pairs. Verify that typing `(` before an unmatched `)` reuses it and typing inside a matched `()` makes a nested pair.
- Use Tab at different starting columns and on a blank line inside a block. Backspace through a leading indent and a fresh auto-pair, including Undo. Split pairs across two Focus blocks in a CRLF buffer, and check Return after a Python block header.
- Click the filename and change the width and style in the popover. Reopen the file, switch to another file with detected tabs, and return to Automatic. Hold a file switch and verify that the indentation settings, title and text change together.
