# Worktree sidebar

Worktree browses the contents of the folder open in the current window. Use Shift-Command-E or the sidebar’s menu to show and focus it. Press Shift-Command-E again from Worktree to restore the previous focus. Command-B toggles sidebar visibility. The Search and Worktree modes share the native, full-height sidebar. Each window restores its mode and visibility independently.

The native outline starts with the opened folder's contents at the first level. It shows folders before files and loads one level at a time. A folder uses only its disclosure chevron, aligned with the file icons at the same depth. Chevrons use the system secondary label tint and follow the native selection contrast. A single primary click on a file opens it through the normal opening and autosave flow and keeps keyboard focus on its row. Up and Down move between rows and open files as they are selected. Space focuses the editor after any pending file open. Return opens the rename dialog for the selected item when Rename is available. Command-click and Shift-click select rows for file operations. Opening a file selects its row and reveals its parent folders. Selected names retain their regular weight. The highlight leaves a small margin at either sidebar edge and space before the chevron. Visible folders can be collapsed after a reveal. An open file outside the worktree appears with its parent path below the worktree.

Files and folders matched by .gitignore appear in gray. By default, the tree hides dotfiles, Finder-hidden items, and paths hidden through the context menu. The Worktree toolbar menu has a Show Hidden Files toggle. Manually hidden paths are remembered for that worktree. These filters always include the current file and its parent folders.

The context menu reveals items in Finder, copies items or their paths, pastes files, opens files with registered apps, renames items, and moves them to the Trash. The folder menu creates files or folders from relative names that may contain subfolders. Use the blank-area context menu or the Worktree toolbar menu to create them in the root of the opened folder. Directory changes are reflected while the tree is visible. File operations keep open buffers associated with their new paths after a rename or move.

Drag files and folders between folders in Edit, or use Option to copy them. Drops from other apps copy items into the target folder. Drag out of Edit to share standard file URLs with other apps. Existing destination items are protected from being overwritten.

## Acceptance

Open Worktree in a folder and switch between it and Search. Hide a folder containing the current file and confirm the file is still listed. Verify that the root contents start at the first level and that both menus offer creation in the root. Collapse a folder and refresh. Check that it stays collapsed and its siblings remain visible. Confirm ignored rows stay navigable and gray, and Show Hidden Files reveals both manually hidden and system-hidden entries. Exercise creation, rename, copy, paste, Trash and drops using disposable files.
