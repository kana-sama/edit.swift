# Worktree sidebar

Worktree browses the contents of the folder open in the current window. Use Shift-Command-E or the sidebar’s menu to show and focus it. Press Shift-Command-E again from Worktree to restore the previous focus. Command-B toggles sidebar visibility. The Search and Worktree modes share the native, full-height sidebar. Each window restores its mode and visibility independently.

The native outline starts at the top of its scroll area with the opened folder's contents at the first level. It shows folders before files and loads one level at a time. A folder uses only its disclosure chevron, aligned with the file icons at the same depth. Chevrons use the system secondary label color and follow the native selection contrast. Opening and closing context menus preserves those colors. A single primary click on a file opens it through the normal opening and autosave flow and keeps keyboard focus on its row. Up and Down move between rows and open files as they are selected. A disclosure click or double-click on a folder row uses the native outline animation. Child rows slide out from beneath the folder on expansion and back beneath it on collapse, moving with the following rows. The outline column follows the sidebar width at every level of indentation. Space toggles the focused folder. Left collapses and Right expands all selected folders, keeping the visible items selected and keyboard focus in Worktree. Collapsing a parent preserves its descendants’ expansion state. Keyboard disclosure updates without animation, including when children first arrive from disk. Space on a file focuses the editor after any pending file open. Return starts editing the selected name in its row when Rename is available. Command-click and Shift-click select rows for file operations. Opening a file selects its row and reveals its parent folders. Selected names retain their regular weight. The highlight leaves a small margin at either sidebar edge and space before the chevron. Adjacent selected rows form a continuous highlight with rounded outer corners. Gaps in the selection separate the highlighted groups. Visible folders can be collapsed after a reveal. An open file outside the worktree appears with its parent path below the worktree.

Files and folders matched by .gitignore appear in gray. By default, the tree hides dotfiles, Finder-hidden items, and paths hidden through the context menu. The Worktree toolbar menu has a Show Hidden Files toggle. Manually hidden paths are remembered for that worktree. These filters always include the current file and its parent folders.

The context menu reveals items in Finder, copies items or their paths, pastes files, opens files with registered apps, renames items, and moves them to the Trash. The context menu and Command-Delete move the entire selection to the Trash in one operation. After a successful removal, Worktree keeps keyboard focus in the outline and selects the first surviving visible row below the topmost removed row, or the preceding row at the end of the tree. If part of the selected group remains, it stays selected. An empty tree keeps focus with an empty selection. Undo selects the restored items that were selected before deletion and reveals their parent folders. With Worktree focused, Command-Z undoes a completed rename or Trash operation, and Shift-Command-Z redoes it. Undo and redo of a rename reveal and select the renamed item in the focused tree. File history belongs to the open folder in that window. Restoring from the Trash returns items to their original paths and preserves any files now at those paths. Rename selects the file basename or the full folder name. New File and New Folder display an editable provisional row under the destination folder. Use the blank-area context menu or the Worktree toolbar menu to create items in the root. Creation accepts a relative path with subfolders. Return submits the name. Escape or leaving the field cancels unsubmitted edits. A failed operation keeps the typed name available for correction. Directory changes are reflected while the tree is visible, and refreshes preserve active name editing. File operations keep open buffers associated with their new paths after a rename or move.

Drag files and folders between folders in Edit, or use Option to copy them. Drops from other apps copy items into the target folder. Drag out of Edit to share standard file URLs with other apps. Existing destination items are protected from being overwritten.

## Acceptance

Open Worktree in a folder and switch between it and Search. Hide a folder containing the current file and confirm the file is still listed. Verify that the root contents start at the first level and that both menus offer creation in the root. Collapse a folder and refresh. Check that it stays collapsed and its siblings remain visible. Confirm ignored rows stay navigable and gray, and Show Hidden Files reveals both manually hidden and system-hidden entries. Create and rename items in their tree rows using disposable files. Check Escape before confirming a rename, then Command-Z and Shift-Command-Z after completing a rename. Verify the row and keyboard focus for both files and an expanded folder whose child is open in the editor. Check a conflicting name and creation with subfolders. Exercise copy, paste, Trash and drops. Use the [native interaction checklist](../../design.md#verifying-native-interactions) with Finder list view and the same layout in Edit. Select neighboring rows, then deselect an interior row with Command-click and check that the highlight splits into rounded groups. Press Right on a branch whose contents have not loaded, then Left and Right again. Repeat with two folders, with an additional file selected, and with a parent and its expanded child selected. In Edit the neighboring rows snap to their new positions for keyboard disclosure and animate for mouse disclosure. The reference for mixed selection and nested branches is stock AppKit NSOutlineView on macOS 27.2.1. Delete a middle item, the last item, a disjoint group, an expanded folder with a selected child, and all rows. Confirm the successor, predecessor, or empty selection and keyboard focus, then undo and check the original selection.
