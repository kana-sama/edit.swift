# Folder context

File → Open… (⌘O) accepts folders and files. The terminal launchers `edit [path ...]` and `./script/run [path ...]` accept both. By default, a folder opens in the current editor window through the usual autosave and draft confirmation. Use [Open in Another Window](../open-in-another-window/spec.md) to open it in a new window. Cancel keeps the current folder and buffer. A window can have one document and one folder context. Opening another folder in that window replaces its context. Opening a file or creating a new buffer keeps the context. File → New Window starts without a folder.

Open the last file opened within the folder if it is readable. Otherwise show **No File Open** in the center of the document area with **Press ⌘P to open a file.** and **Press ⌘W to close the folder.** The screen has no editable document. The owner can open a file from it or create an untitled document with ⌘N. Opening or first saving a file inside the folder updates its remembered file. An outside file leaves it alone.

⌘W closes the current file, preview, or untitled document and shows **No File Open** in the same folder window. From **No File Open**, ⌘W closes the window and its folder context. Holding ⌘W performs at most one step. The red window button closes the entire window and its folder context without switching to **No File Open** first. Both actions finish autosave and handle any unsaved changes through the usual [close rules](../files/spec.md#new-close-and-restore). Cancel leaves the current window and its document open.

File → **Close Workspace** and **File: Close Workspace** in Command Mode remove the folder context from the current window. If the window shows a file or preview from that folder, finish autosave and apply the usual close rules. Keep the current title and presentation until the empty, editable **Untitled** buffer is ready. **No File Open** also becomes **Untitled**. An already open untitled draft, scratch, or file outside the folder stays open with its selection. Hide Worktree or Jujutsu when it is the visible sidebar. The window stays open, and Close Workspace is available again when a folder is opened in it.

File → Open Recent shows the ten most recently opened folders before a separator and up to ten files from the [active project's and shared histories](../recent-files/spec.md). Choosing a folder follows the same rules as Open. A folder's remembered file persists across launches and is independent of the menu limit.

With a folder open, a nonempty ⌘P query searches recent files and regular files within the folder according to the [Control folder search rules](../control/spec.md). Clearing the query shows eligible pins followed by recent files, including [recent scratches associated with that folder](../scratch-files/spec.md#go-to-file).

The title bar displays the folder name. An open document adds its file name or “Untitled”. Show the full file name whenever it fits in the title area above the exposed editor. Truncate it in the middle when the window or sidebars leave less room. Update the width when switching files, resizing the window, or changing either sidebar. Secondary-click or Control-click the folder name for recent folders or the file name for files in the same directory, including when the toolbar is revealed in full screen. The native menus align with their title labels and show an icon next to each entry. Drag either label to move the window. Choosing an entry replaces the buffer or folder in that window through the regular Open command. Session restoration reopens the folder with its current document, draft, or empty screen. If the current file is missing or unreadable and there is no draft, show **No File Open** in the restored folder window.

## Acceptance

- Open a folder containing a README using ⌘O and the terminal launcher. Verify window reuse, the empty screen, and both shortcuts. Open a file inside the folder, switch away, and reopen the folder from Open Recent to recover that file. Delete the remembered file, then reopen the folder to check the empty screen again.
- Press ⌘W on an edited file in a folder window. Verify its edits reach disk and the window stays open on **No File Open**. Press ⌘W again to close the window. With another file open in a folder window, click the red button and verify that the window closes directly after saving. Invoke ⌘N on the empty screen, edit the new draft, and cancel a close from the red button and a folder switch to check that both its text and folder stay intact.
- With Worktree visible, invoke Close Workspace on an edited file in the folder. Verify the pending presentation and title, then verify the file reaches disk and the first standalone presentation is an editable **Untitled** in the same window. Repeat from **No File Open**, an external file, and an unsaved untitled draft. Verify that Close Workspace and Worktree are unavailable in the standalone window and that reopening the folder recovers its remembered file.
- Compare ⌘P with an empty query and with a query for a nested file that has never been opened.
- With Worktree and the right-docked terminal open, widen the terminal until the file name truncates. Narrow the terminal again and verify the full file name returns while the same file stays open.
- Quit with multiple folder windows, including a named file, an untitled draft, and the empty screen of a folder that remembers a file. Reopen Edit and verify the folder names, geometry, and contents of each window.
