# Control · Go to File

File → Go to File… (⌘P) opens a centered native palette of recent named files. The empty query shows the most recent first. Type case-insensitive fuzzy terms against the names and directories. Each term must match, terms may appear in any order, and a backslash can escape a literal space. Prefer a matching filename to a matching directory. Highlight the matching characters. Resolve queries off the UI thread and keep outdated rows inert until the latest results arrive. Use the system menu material and one borderless search row with a leading magnifier, text field, and a trailing clear button when a query is present. A thin separator divides the search row from compact results. Inset the rounded system-accent selection and keep the row and shortcut padding balanced across modes. The results area reaches the panel edge and fits whole rows up to the height limit. Match the space after the last row to the inset above the first row. Scroll longer lists without a visible scrollbar.

Up and Down wrap through results. Unmodified Return and row clicks open the selected file in the current window. Escape, ⌘W, and repeated ⌘P dismiss the palette and restore the original focus. While Control has focus, text navigation, clipboard commands, and undo operate on its search field. Document shortcuts such as ⌘Return, ⌘N, and ⌘S have no effect. ⌘F and ⌥⌘F dismiss the palette and focus Find or Replace, and ⌘Q still quits Edit. Clicking outside dismisses the palette and still performs the click. The trailing dismiss control of an active row removes it from the shared [recent history](../recent-files/spec.md). An opening error keeps the query and shows the reason.

Swift Edit uses [autosave](../autosave/spec.md) when Control takes focus and when it opens a file. An edited scratch buffer gets the save or discard prompt before replacement. Cancel returns to the current buffer.

## Acceptance

Open documents, close one, and open Control. Filter by name and path, navigate in both directions, and open an entry with Return. Check that the file opens in the current window, even if another window has the same path, and that recently deleted paths can be removed. With two results, select the second row and verify that both fit without scrolling. Scroll a long list, then narrow it to two results and check that the list returns to the top. Escape returns to the previous focus. With Control open, verify that ⌘Return does not insert a line, ⌘W closes the palette, and ⌘A and ⌘Z operate on the query.
