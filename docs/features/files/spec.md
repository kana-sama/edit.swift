# Files

Edit opens and saves plain-text files. New documents default to UTF-8. Each window has one document and shows its file’s basename or “Untitled” in the title bar. In a [folder window](../folders/spec.md), the title also shows the folder name. The title content has an 8-point leading inset for both file and folder windows, with the sidebar open or closed. A named file uses the same Seti icon here as in Control. macOS indicates unsaved changes in the window’s close button. Each window uses the text surface and editing commands in the [Editor specification](../editor/spec.md).

## Open and save

- Use Command-O to select a file or [folder](../folders/spec.md) in the native open panel. Open Recent, Control, Finder’s Open With menu, `edit [path ...]`, and `./script/run [path ...]` also open files. All of these replace the buffer in the window that received the command. Multiple paths delivered by Finder or the launcher are processed in order in that window. Cancel stops the sequence. Paths passed to the launcher are relative to the caller’s directory. If the requested file or an equivalent path, symlink, or hard link is the current buffer, keep its text, selection, and undo history. The native Open panel runs separately from the editor so a stalled system file dialog leaves Edit responsive. A repeated Open command brings the pending chooser forward when available. If it fails to appear, show an error and allow another attempt. Once visible, it stays open until the user chooses or cancels.
- Reopening one of the last 100 named files left in the editor restores its horizontal and vertical scroll position, primary caret, additional carets, and selected ranges. Store the position when replacing the buffer, closing its window, or quitting, and keep it across launches. Opening the same file through an equivalent path uses its saved position. Clamp the restored view and ranges to the available content if the file has changed.
- To edit a file that does not exist yet, pass its path to `edit`, `./script/run`, or the app bundle’s executable. The parent directory must exist. The document starts empty and the file is created on Save or when the edited buffer autosaves.
- Use Command-S to save to the current path, or select a path in the native save panel for an untitled document. Use Shift-Command-S to save under a new name or with a different encoding. Save panels provide a native encoding menu and start with the current buffer’s encoding. Cancel either panel to continue editing with the same text and document path.
- Two windows created explicitly with New Window can each show the same file. Each buffer checks its disk revision before writing, so a stale buffer prompts before overwriting a newer save.
- Opening recognizes Unicode byte order marks and supported macOS encoding hints, with UTF-8 as the fallback. Saving preserves the encoding, byte order mark and existing line endings unless the user changes the encoding. Save in a chosen encoding only if it can represent the entire text. Show an error when a file is missing, unreadable, or cannot be decoded. If a file on disk has changed or been removed since opening or saving it, ask before saving to that path.

## New, close, and restore

- Command-N replaces the current document with an empty untitled buffer in the same window. Preserve the window and its geometry, reset the selection and undo history, and focus the editor. Command-Shift-N or File → New Window opens a separate empty editor window.
- Before Open, New, or Close, let any pending write finish and [autosave](../autosave/spec.md) the outgoing named document. If the buffer is still edited, use the appropriate confirmation below. Cancel or a failed manual save keeps the current buffer.
- Command-W closes the current window. When closing or replacing an edited untitled document, use AppKit’s document close sheet. It places the heading and explanation above the name and destination fields, with Delete at the leading edge of the footer and Cancel and Save at the trailing edge. Show a native encoding menu in its own row above the footer. Size that row from its controls so expanding Where does not widen later compact sheets. Hide the Tags field and the extension option. Delete discards the draft without writing a file.
- For a document with a path and edits left after autosave, offer Save, Don’t Save, and Cancel. Closing after Save requires a successful write. Cancel keeps the current window and changes. Closing the last window exits Edit and remembers its frame for the next new window.
- Command-Q finishes pending writes, attempts autosave for dirty named buffers, and atomically saves the session, including open windows, the active window, and any remaining drafts. On relaunch, load clean files from disk and restore unsaved text from the drafts. Report files that are missing or unreadable.
- Restore each window’s position, size, full-screen state, document scroll position, carets, and selections. Remember the normal window frame when a window goes full screen. If a saved frame is off the available displays, restore the window on an available screen.

## Acceptance

- Open and save a UTF-8 file with a BOM and mixed line endings. Edit its text, then check that the BOM and existing line breaks survive saving.
- Open existing files from the native panel, Finder, and the terminal. Run the launcher from a different directory with a relative path that includes spaces. Open a different file over a named buffer and verify the same window is reused. Repeat over an untitled draft and check Save and Cancel. Simulate a picker that stalls before appearing and confirm Edit can receive events, suppress duplicate requests, and retry. Open a link to the file already in the current window and check that its selection is preserved.
- Scroll both ways in a long file and place multiple carets and selections. Switch to another file and return through Open Recent. Close its window and open the file from a new one. Check that both scroll axes and the selected ranges return, including when the primary caret was outside the visible area. Verify that two windows showing the same file restore their own positions after quitting.
- Create an untitled document, cancel the save panel, then save it. Use Save As to continue editing a second file. Pass a new path to the app executable and verify that Save creates the file even when its buffer is empty.
- Modify or remove an open file externally and attempt to save. Cancel the confirmation and verify the document stays open with its edits. Check all three choices when closing a modified window.
- From a dirty named buffer press Command-N and verify the same window becomes untitled after its file is written. Repeat with an edited untitled buffer and cancel to keep the text. Use Command-Shift-N and verify a separate empty window opens.
- Close an edited untitled document. Check that the compact native sheet lets you choose a destination and encoding, starting with Untitled.txt and UTF-8. Expand Where, cancel, and reopen the sheet. When compact, it should have its original width. Verify Save and reopen for UTF-16 and Windows Cyrillic, and try an encoding that cannot represent the text.
- Quit with clean and dirty documents, including an untitled draft and a full-screen window. Verify that eligible named edits reach disk and that untitled or failed named writes are recoverable as drafts. Relaunch and check the drafts, the saved documents, the active window, and window geometry.
