# Sidebar Menu

An ellipsis button at the right edge of the sidebar header opens a native menu for choosing the active sidebar. Search is the only entry and is checked while active. Choosing Search focuses its query field and keeps the current query. The menu button and Refresh use the compact unified window toolbar. The buttons appear when the sidebar finishes opening and disappear when it starts closing.

## Acceptance

Open the sidebar and choose Search from the ellipsis menu. Verify that Search is checked, the query stays intact, and the field receives focus. Close and reopen the sidebar and verify that both buttons follow its visibility.
