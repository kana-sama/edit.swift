# Sidebar Menu

An ellipsis button at the right edge of the sidebar header opens a native menu aligned to the button’s right edge. Search and Worktree are always listed. The active sidebar is checked. Choosing Search focuses its query field and keeps the current query. [Worktree](../worktree/spec.md) is disabled until the window has an open folder. A separator follows the sidebar list. Search offers Refresh Search, and Worktree offers Show Hidden Files. The icon-only menu button appears when the sidebar finishes opening and disappears when it starts closing. Command-B toggles the sidebar in its last mode. Command-F always opens Search and focuses the Find field.

## Acceptance

Open the sidebar and choose Search from the ellipsis menu. Verify that Search is checked, the query stays intact, and the field receives focus. Dismiss a result, then choose Refresh Search below the separator to restore it. Close and reopen the sidebar and verify that the menu button follows its visibility.
