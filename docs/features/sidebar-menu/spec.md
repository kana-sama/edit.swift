# Sidebar Menu

An ellipsis button at the right edge of the sidebar header opens a native menu for choosing the active sidebar. Search is the only entry and is checked while active. Choosing Search focuses its query field and keeps the current query. A separator follows the sidebar list. Refresh Search appears under it and runs the current search again. The icon-only menu button appears when the sidebar finishes opening and disappears when it starts closing.

## Acceptance

Open the sidebar and choose Search from the ellipsis menu. Verify that Search is checked, the query stays intact, and the field receives focus. Dismiss a result, then choose Refresh Search below the separator to restore it. Close and reopen the sidebar and verify that the menu button follows its visibility.
